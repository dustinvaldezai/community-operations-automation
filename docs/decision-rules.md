# Decision Rules

A useful operations workflow needs explicit boundaries for what can move through a routine path and what should stop for human judgment.

These rules are a public-safe demonstration, not a claim about the exact internal rules used in the original garden workflow.

## Routine path

A request can move through the routine path when all of the following are true:

- the request matches a known category
- the response can be based on an approved template or established information
- no sensitive personal information is involved
- no financial, legal, safety, disciplinary, or policy decision is required
- no new commitment is being made on behalf of the organization
- the message does not contain a dispute, complaint, emergency, or ambiguous situation

## Human-review path

Escalate when any of the following applies:

- the sender is asking for an exception
- the response would create a new promise, commitment, or deadline
- the request involves conflict, complaints, or sensitive circumstances
- the available information is incomplete or contradictory
- a response could materially affect access, safety, finances, policy, or another person
- the tone or context requires judgment rather than a standard answer

## Example classification logic

| Request type | Default path | Reason |
| --- | --- | --- |
| Basic hours / access question | Routine | Usually answered from established information |
| Workshop interest | Routine + follow-up | Can use a standard acknowledgment and log next action |
| Volunteer inquiry | Routine + follow-up | Often needs structured intake before human scheduling |
| Complaint or interpersonal conflict | Human review | Requires context and judgment |
| Request for an exception | Human review | Changes or interprets an existing rule |
| Safety issue | Human review | Higher consequence |
| Unknown or ambiguous request | Human review | Avoid confident automation when classification is weak |

## Principle

When in doubt, the workflow should fail toward review rather than fabricate certainty.
