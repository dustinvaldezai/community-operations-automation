# Human Review Checklist

Use this checkpoint before a drafted operational response is sent when the workflow flags review.

## Accuracy

- Does the response answer only what is known?
- Are dates, times, names, commitments, and instructions confirmed?
- Does the draft avoid inventing missing details?

## Judgment

- Is a human decision actually required here?
- Does the response create or imply a new commitment?
- Could the message affect access, safety, finances, policy, or another person?

## Tone and usability

- Is the response clear and respectful?
- Is the next action obvious?
- Is unnecessary jargon removed?
- Would the recipient understand what happens next?

## Privacy

- Is any sensitive personal information included unnecessarily?
- Is the response going to the correct recipient?
- Should any part of the message be handled outside an automated path?

## Follow-up

- Does this request need a reminder or owner?
- Has the next action been recorded?
- Is there a deadline that should not depend on memory?

## Final rule

If any answer is uncertain, do not force completion through automation. Return the case to human review.
